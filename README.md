# ToDo-RicH

# This project is a productivity-focused Android app for managing personal tasks,
# organizing categories, filtering and sorting tasks, and keeping everything stored locally.

## Features
- Create, edit, delete, complete, and reactivate tasks
- Title and description support with priority selection
- Due date and due time scheduling
- Task categories with creation, rename, and delete flows
- Search, filter, and sort tasks in real time
- Persistent local storage through Room
- Light and dark theme support with Material 3
- Accessibility and validation-friendly interface

## Technology Stack
- Kotlin
- Jetpack Compose
- Material 3
- Room
- ViewModel + StateFlow
- Navigation Compose
- Kotlin Coroutines

## Build
From the project root, run:

```bash
./gradlew assembleRelease
```

## APK Output
The generated APK is written to:

```text
app/build/outputs/apk/release/
```
